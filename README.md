# Симулятор самолётного БПЛА

Симулятор беспилотника самолётного типа на Python: модель движения 6DOF,
написанная с нуля, САУ с расчётом коэффициентов по модели, навигация по точкам,
3D-тренажёр с пилотированием в реальном времени, учебный стенд, где коэффициенты
регуляторов крутятся ползунками прямо в полёте, и конструктор САУ из блоков.

Без сторонних физических движков: уравнения движения, аэродинамика и интегратор
написаны вручную и открыты для чтения — проект задуман как инструмент, в котором
понятна каждая строка.

---

## Что умеет

**Физика**
- Полная модель 6DOF: состояние `[u, w, q, θ, x, h, v, p, r, φ, ψ, y]`,
  управление `[δe, δt, δa, δr]` (руль высоты, тяга, элероны, руль направления).
- Нелинейная аэродинамика продольного канала со срывом (sigmoid-смешение
  линейной модели и плоской пластины), боковые коэффициенты, тензор инерции с Jxz.
- Ветер: постоянный, порывы, сдвиг по высоте; аэродинамические углы считаются
  по воздушной скорости.
- Силовая установка — электромотор + винт по паспортным и продувочным данным;
  приводы рулей (инерция, скорость перекладки); твёрдая земля и трёхопорное шасси.
- Интегратор RK4 (Эйлер — опция); физика — чистая функция `derivatives()`,
  отдельно от численного метода.

**Управление**
- Все коэффициенты считаются по модели ЛА (метод последовательного замыкания
  контуров), а не подбираются; для другого ЛА — тот же вызов.
- Продольный канал: каскад θ → q → δe, высота и скорость — TECS (управление полной
  энергией) или раздельные контуры; LQR как альтернатива.
- Боковой канал: крен и курс по схеме PX4/ArduPilot, координированный разворот,
  работа при боковом ветре.
- Навигация по точкам: следование по прямой и окружности векторным полем,
  скругление углов маршрута дугой, кружение вокруг последней точки
  (Beard & McLain, гл. 10–11).
- Автомат защиты от выхода на закритические углы атаки.
- Псевдодатчики с шумом и смещением: гироскоп, ИНС, барометр, ПВД, GPS, датчики
  углов атаки и скольжения.

**Визуализация и интерактив**
- 3D-тренажёр на Ursina: пилотирование с клавиатуры или через САУ, четыре камеры,
  проигрывание записанных полётов.
- Карты: учебная 10×10 км (ВПП, река, озеро, деревня, холм, леса) и реальный
  аэродром Каинки — спутниковый снимок на рельефе SRTM или стилизация по
  OpenStreetMap.
- Окно наземной станции: PFD, карта (маршрут ставится мышью, САУ летит по точкам), рули, α/β, TECS, журнал событий.
- Стенд САУ: блок-схемы контуров с ползунками коэффициентов, живыми сигналами,
  ступеньками уставок, «толчками» рулей и осциллографом.
- Конструктор САУ: схема из блоков (термины ТАУ) ведёт любые из рулей прямо в полёте.
- Запись каждого полёта в `.flightlog`; 2D-графики и анимация лога, 3D-проигрыватель.

## Установка

```bash
git clone https://github.com/der-rozanov/Sim
cd Sim
pip install -r requirements.txt
```

Версии в `requirements.txt` закреплены (`==`) — на них проверен проект.

| Пакет | Где нужен |
|---|---|
| `numpy`, `matplotlib` | везде (ядро, графики) |
| `scipy` | только LQR (`control/lqr.py`) |
| `ursina` (тянет `pillow`) | только 3D: тренажёр, стенд, карты |

Python 3.12 (проверено на 3.12.10). Спутниковый снимок и рельеф для карты Каинки скачиваются при первом
запуске в `viz/map_cache/` (в репозиторий не входят).

## Быстрый старт

```bash
python scenarios/GameScenario3D.py            # полёт в 3D + окно станции
python scenarios/Bench3D.py                   # стенд САУ: 3D + блок-схемы + карта
python scenarios/Bench3D.py --map kainki --wind-e 5
python scenarios/BlockLab3D.py                # конструктор САУ: 3D + редактор схем

python scenarios/s10_waypoints.py             # полёт по точкам: отчёт + графики
python viz/viewer.py                          # графики и анимация любого .flightlog
python viz/viewer3d.py                        # пересмотреть последний полёт в 3D
python checks/check.py                        # самопроверка: ALL CHECKS PASSED
```

**Клавиши 3D-тренажёра** (подробно — [docs/viewer3d.md](docs/viewer3d.md)):

| | Ручной режим | С САУ (P — вкл/выкл) |
|---|---|---|
| W / S | руль высоты | уставка тангажа / высоты |
| A / D | элероны | уставка путевого угла ∓10° |
| Q / E | руль направления | — |
| X / Z | тяга | уставка скорости |
| Shift | большие расходы рулей (±10°) | — |
| H / N | — | удержание высоты / полёт по маршруту |

Пробел — пауза, R — сброс, 1–4 — камера, Esc — выход.

**Окно станции (карта):** ЛКМ — поставить или перетащить точку, ПКМ — удалить, колесо над
точкой — её высота, над картой — масштаб; `FLY` — полёт по маршруту.

## Устройство

Слои зависят только от нижележащих:

```
sim/        физика 6DOF: параметры, состояние, динамика, аэродинамика, ветер, интеграторы
control/    САУ: регуляторы, датчики, навигация, защита по α, LQR
runner.py   главный цикл run() → Log, балансировка;  flight_logger.py — .flightlog
viz/        графики, 2D/3D-проигрыватели, миры и карты, окна стенда и карты
scenarios/  прогоны s1–s10, 3D-тренажёр, стенд САУ, конструктор САУ
archive/    код вне основной линии (сравнение «зонд vs косвенная оценка УА»)
checks/     проверки здравого смысла и сверка с линейной теорией
docs/       документация
```

Принципы:
- состояние — один numpy-вектор с именованными индексами;
- `derivatives(state, controls, t)` — чистая функция, интеграторы взаимозаменяемы;
- управление заморожено на шаг интегрирования, как в цифровой САУ;
- параметры ЛА, ветра и датчиков — в конфиге, в коде нет «зашитых» чисел физики;
- визуализация полностью отделена от расчёта.

## Параметры ЛА

По умолчанию — FPV-самолёт классической схемы класса 1.8 м (m = 2 кг, крыло
1.8 × 0.25 м); геометрия и масса — оценка, производные посчитаны по геометрии
учебными формулами (`checks/estimate_fpv_aero.py`). Силовая установка — реальные
данные: мотор T-Motor AT2814 900KV (паспорт) и винт APC 11×7E (продувка UIUC).
Крейсер 16 м/с, сваливание ≈ 7.5 м/с. Прежний аналог Aerosonde — пресет
`aerosonde_params()`. Свой ЛА — параметры в `sim/config.py` и регистрация в
`AIRCRAFT_TYPES` (флаг `--aircraft`). Числа, полученные в симуляторе, — результаты
моделирования, не эксперимента.
