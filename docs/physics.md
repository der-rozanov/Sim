# Физическая модель симулятора

Источник: Beard & McLain «Small Unmanned Aircraft», гл. 3–4.  
Реализация: `state.py`, `dynamics.py`, `aero.py`, `wind.py`.

---

## 1. Системы координат

### 1.1 Земная (инерциальная) СК

Оси: **x** — горизонталь вперёд по направлению полёта, **h** — вертикаль вверх.  
В этой СК хранятся позиция `(x, h)` и задаётся ветер.

```
h (вверх)
^
|
+-------> x (горизонталь вперёд)
```

### 1.2 Связанная СК тела (`body frame`)

Оси: **x_b** — к носу, **z_b** — вниз (вдоль брюха), **y_b** — вправо (правая СК).  
В этой СК хранятся скорости `(u, w)` и действуют уравнения Ньютона.

```
x_b (к носу)
^
|  y_b (вправо, из экрана)
| /
|/
+-------> z_b (вниз)
```

### 1.3 Угол тангажа θ

Угол поворота связанной СК относительно земной вокруг оси y.  
**θ > 0** — нос выше горизонта.

Поворот ветра из земной СК в связанную (используется в `state.air_velocity`):

```
u_wind_body =  Vwx·cos(θ) + Vwh·sin(θ)
w_wind_body =  Vwx·sin(θ) − Vwh·cos(θ)
```

### 1.4 Угол атаки (УА) α и воздушная скорость Va

Вычисляются из **воздушных** (relative to air mass) скоростей:

```
ur = u − u_wind_body   (воздушная скорость вдоль x_b)
wr = w − w_wind_body   (воздушная скорость вдоль z_b)

Va    = √(ur² + wr²)
alpha = arctan2(wr, ur)
```

**Принципиально**: УА считается по воздушной скорости, не по земной.  
Именно поэтому при ветре косвенная оценка `α ≈ θ − γ_GPS` даёт ошибку —  
`γ_GPS` считается по земной скорости, которая не учитывает ветер.

## 2. Вектор состояния

```
state = [u, w, q, θ, x, h]   (numpy array, 6 элементов)
```

| Индекс | Имя | Описание | Ед. |
|--------|-----|----------|-----|
| 0 | `u` | Скорость вдоль x_b (вперёд) | м/с |
| 1 | `w` | Скорость вдоль z_b (вниз) | м/с |
| 2 | `q` | Угловая скорость тангажа | рад/с |
| 3 | `θ` | Угол тангажа | рад |
| 4 | `x` | Горизонтальная координата | м |
| 5 | `h` | Высота (вверх положительно) | м |

Доступ по имени (файл `state.py`):
```python
from state import U, W, Q, THETA, X, H
u = state[U]      # вместо state[0]
```

## 3. Уравнения движения

Реализованы в `dynamics.derivatives()`. Ниже — дословная запись, которую  
можно перенести в приложение Б диссертации.

### 3.1 Поступательное движение (2-й закон Ньютона в связанной СК)

```
du/dt = (fx_aero + fx_thrust + fx_grav) / m  −  q·w
dw/dt = (fz_aero           + fz_grav) / m  +  q·u
```

Члены `∓ q·w` и `± q·u` — кориолисовы ускорения: они возникают потому,  
что скорости `u, w` определены во **вращающейся** связанной СК.

### 3.2 Вращательное движение

```
dq/dt = M_pitch / Jy
```

`M_pitch` — момент тангажа от аэродинамики (момент тяги и веса равен нулю  
при расположении ЦТ на оси тяги).

### 3.3 Кинематика

```
dθ/dt = q
dx/dt = u·cos(θ) + w·sin(θ)
dh/dt = u·sin(θ) − w·cos(θ)
```

Последние два уравнения — проекция вектора скорости тела на земные оси.
Вывод из матрицы поворота `R_b^e(θ)`: второй столбец (для w) имеет знаки `[+sin θ, −cos θ]`.

**Проверка знаков** при θ=0, прямолинейный полёт (u=Va, w=0):
- `dx/dt = Va` ✓ (летим вперёд)
- `dh/dt = 0` ✓ (горизонтальный полёт)

При θ=0, w>0 (сваливание вниз по связанной оси z_b):
- `dh/dt = -w` ✓ (высота убывает, z_b смотрит вниз)

При θ=45°, u=Va·cos(α), w=Va·sin(α), α=0 (нос ровно под 45°):
- `dx/dt = Va·cos²(45°) + Va·sin(45°)·sin(45°) = Va·(0.5 + 0.5) = Va` ✓
- `dh/dt = Va·cos(45°)·sin(45°) − Va·cos(45°)·sin(45°) ... → ḣ = Va·sin(γ)` ✓

## 4. Силы

### 4.1 Гравитация в связанной СК

```
fx_grav = −m·g·sin(θ)    (тянет нос вниз при θ > 0)
fz_grav = +m·g·cos(θ)    (давит по z_b, т.е. вниз относительно тела)
```

### 4.2 Тяга

Тянущий винт, ось — вдоль x_b. Модель Beard & McLain (упрощённая):

```
T = 0.5 · ρ · S_prop · C_prop · ((k_motor · δt)² − Va²)
```

Физический смысл: двигатель разгоняет воздух с `k_motor·δt` до бесконечности,  
создавая тягу пропорционально разнице скоростей потока.  
При `δt=0` и `Va>0` тяга может стать отрицательной (торможение от неподвижного  
винта) — это корректно для свободного планирования.

### 4.3 Аэродинамические силы

Подъёмная `L` и сопротивление `D` определяются в **скоростной (поточной) СК**  
(x_s вдоль Va), затем поворачиваются в связанную через угол α:

```
fx_aero = −D·cos(α) + L·sin(α)
fz_aero = −D·sin(α) − L·cos(α)
```

Знаки: при малом α и нормальном полёте:
- `fz_aero ≈ −L < 0` — направлена вверх (против z_b), удерживает от падения ✓
- `fx_aero ≈ −D < 0` — направлена назад, тормозит ✓

## 5. Балансировочные условия (трим)

Горизонтальный полёт: `du/dt = dw/dt = dq/dt = dθ/dt = 0`, `γ = 0`.

Из условия `L = mg`:

```
CL_req = 2·m·g / (ρ·Va²·S)
```

Из `CL = 0` и `Cm = 0` — линейная система 2×2 для `(α_trim, δe_trim)`:

```
[CLa   CLde] [α   ]   [CL_req − CL0]
[Cma   Cmde] [δe  ] = [−Cm0        ]
```

Из `T = D` — газ `δt_trim`. Реализовано в `runner.compute_trim()`.

## 6. Механическая энергия

```
E_kin   = 0.5 · m · Va²
E_pot   = m · g · h
E_total = E_kin + E_pot
```

**Va** здесь — воздушная скорость (учитывает ветер).  
В тримовом полёте `dE_total/dt ≈ 0` (тяга = сопротивлению).  
Отклонение от этого значения — числовой дрейф интегратора  
(используется в `plot_integrator_check`).

## 7. Ключевые упрощения модели

| Упрощение | Последствие |
|-----------|-------------|
| Только продольный канал (нет крена/рысканья) | Нельзя моделировать повороты; при необходимости — расширить вектор состояния |
| Сжимаемость воздуха не учтена | Корректно до ~150 м/с (число Маха < 0.45) |
| Постоянная плотность воздуха ρ | Погрешность < 1% в диапазоне высот 0–500 м |
| Линейная модель Cm по α | Точна до ~15°; при больших α моменты нелинейны |
| Масса постоянная | Расход топлива не учитывается |
| Тяга вдоль x_b | Реактивный момент от двигателя игнорируется |
