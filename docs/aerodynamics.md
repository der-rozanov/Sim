## 1. Три коэффициента продольного канала

### 1.1 Коэффициент подъёмной силы CL

**Нелинейная модель** (sigmoid-смешение линейного CL и CL плоской пластины):

```
σ(α) = (1 + exp(−M·(α − α₀)) + exp(M·(α + α₀)))
       / ((1 + exp(−M·(α − α₀)))·(1 + exp(M·(α + α₀))))

CL_linear     = CL0 + CLa·α
CL_flat_plate = 2·sign(α)·sin²(α)·cos(α)

CL_base = (1 − σ)·CL_linear + σ·CL_flat_plate
```

Добавки от угловой скорости и руля высоты (квазистационарное приближение):

```
ĉ_q = c·q / (2·Va)   (безразмерная угловая скорость)

CL = CL_base + CLq·ĉ_q + CLde·δe
```

**Зачем sigmoid?**  
При малом α (≲10°) поток ламинарен, CL линейно растёт — используем `CL_linear`.  
После срыва (α > α₀) крыло работает как плоская пластина — переходим к `CL_flat_plate`.  
Параметр M=50 задаёт крутизну перехода: при M→∞ это ступенька.

**Параметры (Aerosonde):**

| Параметр | Значение | Описание |
|----------|----------|----------|
| CL0 | 0.28 | CL при α=0, δe=0, q=0 |
| CLa | 3.45 рад⁻¹ | Производная по α |
| CLq | 0.0 | Производная по q |
| CLde | −0.36 рад⁻¹ | Производная по рулю высоты |
| M_sigmoid | 50 | Крутизна перехода к срыву |
| alpha_stall | 0.4712 рад ≈ 27° | Угол начала срыва |

**Почему CLde отрицателен?**  
В модели Aerosonde `δe > 0` — это отклонение задней кромки руля **вниз** (по правилу правой руки вокруг y_b). Это уменьшает кривизну хвостового оперения → уменьшает его подъёмную силу → CL самолёта падает → `CLde < 0`.  
Следствие: команда «нос вверх» = `δe < 0` (задняя кромка вверх).

### 1.2 Коэффициент сопротивления CD

**Квадратичная модель** (вредное + индуктивное):

```
AR = b² / S         (удлинение крыла)

CD = CDp + CL_linear² / (π·e·AR)
```

- `CDp` — вредное (вязкостное) сопротивление, не зависит от подъёмной силы.
- `CL²/(π·e·AR)` — индуктивное сопротивление: неизбежная плата за подъёмную силу.
- `e` (0.9) — КПД Освальда, учитывает неэллиптическое распределение нагрузки.

**Почему не линейная модель?**  
Линейная CD даёт отрицательные значения при отрицательном α. Квадратичная  
корректно отражает физику: сопротивление всегда положительно, симметрично по α.

### 1.3 Коэффициент момента тангажа Cm

**Линейная модель** (точна при малых углах атаки):

```
Cm = Cm0 + Cma·α + Cmq·ĉ_q + Cmde·δe
```

| Параметр | Значение | Физический смысл |
|----------|----------|------------------|
| Cm0 | −0.02338 | Пикирующий момент при нулевых углах |
| Cma | −0.38 рад⁻¹ | **Устойчивость по тангажу**: Cma < 0 означает, что при увеличении α самолёт автоматически стремится уменьшить α — статически устойчив |
| Cmq | −3.6 | **Демпфирование тангажа**: Cmq < 0 гасит колебания по тангажу |
| Cmde | −0.5 рад⁻¹ | Эффективность руля высоты |

## 2. Перевод сил в связанную СК

Подъёмная сила и сопротивление определены в **скоростной (поточной) СК** (x_s ∥ Va).  
Поворот в связанную СК (вращение на угол α вокруг y):

```
fx_aero = −D·cos(α) + L·sin(α)
fz_aero = −D·sin(α) − L·cos(α)
```

Матрица поворота (2D):
```
[fx_aero]   [cos(α)   sin(α)] [−D]
[fz_aero] = [−sin(α)  cos(α)] [−L]
```

При нормальном полёте (малый α):
- `fz_aero ≈ −L < 0` — тянет против z_b (вверх), удерживает ЛА ✓
- `fx_aero ≈ −D < 0` — тянет против x_b (назад), тормозит ✓

## 4. Замена на авторские данные

Два варианта:

**Вариант A: коэффициенты полинома** (проще, работает из коробки)  
Заменить числа в `config.py`:
```python
CL0 = 0.28   # → ваше значение
CLa = 3.45   # → ваше значение
...
```

**Вариант B: таблица CL(α)** (точнее при нелинейной аэродинамике)  
Добавить в `aero.py` интерполятор:
```python
from scipy.interpolate import interp1d
CL_table = interp1d(alpha_data, CL_data, kind='cubic', fill_value='extrapolate')
```
и заменить `coef_CL` на вызов таблицы. Остальной код менять не нужно.
