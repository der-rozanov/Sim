# Симулятор самолётного БПЛА

Имитационная модель ЛА самолётного типа с фиксированным крылом. Разработана в рамках магистерской диссертации **«Разработка зонда измерения аэродинамических характеристик БПЛА»** (Иннополис, 2025–2026).

Цель — численное подтверждение тезиса: прямое измерение угла атаки (УА) зондом повышает безопасность и эффективность системы автоматического управления (САУ) по сравнению с косвенной оценкой.

## Архитектура

```
Симулятор/
│
├── config.py          # Параметры ЛА, ветра, датчиков, прогона
├── state.py           # Вектор состояния [u, w, q, θ, x, h], именованные индексы
├── aero.py            # CL, CD, Cm (нелинейная модель с sigmoid-срывом)
├── dynamics.py        # derivatives(state, controls, t) — чистая функция
├── integrators.py     # step_rk4, step_euler — взаимозаменяемы
├── wind.py            # wind(h, t) — постоянный ветер, порыв, сдвиг по высоте
├── sensors.py         # Псевдодатчики с шумом (гироскоп, СВС, зонд УА, GPS)
├── control.py         # ПИД-регуляторы: PitchController (θ+q), SpeedController (Va)
├── estimators.py      # Косвенная оценка УА: alpha_est = theta − gamma_gps
├── runner.py          # run(), compute_trim(), trim_state(), print_summary()
├── plotting.py        # Статичные графики (dynamics, trajectory, energy)
│
├── scenarios/
│   ├── s1_steady_flight.py      # С1: Установившийся полёт (балансировка)
│   ├── s2_pitch_up.py           # С2: Кабрирование
│   ├── s3_pitch_down.py         # С3: Пикирование
│   ├── s4_stall.py              # С4: Управляемый срыв + индикатор УА
│   ├── s5_altitude_control.py   # С5: Контроль высоты
│   ├── s6_speed_control.py      # С6: Контроль высоты + удержание Va
│   └── s7_alpha_estimation.py   # С7: Сравнение зонд vs ИНС+GPS при ветре
│
├── results/           # GIF-анимации (генерируются скриптами)
└── check.py           # Санитарная проверка всех модулей
```

### Ключевые архитектурные решения

- **Состояние — единый numpy-вектор** `[u, w, q, θ, x, h]` с именованными индексами — никаких «магических» чисел.
- **`derivatives` — чистая функция** без побочных эффектов, прямая запись системы ДУ (основа Приложения Б диссертации).
- **Управление заморожено на шаг** RK4: внутри k₁…k₄ пересчёт САУ не происходит — соответствует дискретной природе реального контроллера.
- **Аэродинамика** — нелинейная: CL использует sigmoid-смешение линейной модели и модели плоской пластины, корректно воспроизводя срыв при α > α_stall.
- **УА вычисляется по воздушной скорости** (с учётом ветра), не по земной — принципиально для корректного сравнения «зонд vs косвенная оценка».

## Параметры ЛА

Аналог **Aerosonde** (Beard & McLain, прил. E) — будут заменены авторскими данными.

| Параметр | Значение |
|---|---|
| Масса m | 13.5 кг |
| Момент инерции Jy | 1.135 кг·м² |
| Площадь крыла S | 0.55 м² |
| Балансировочная Va | 30 м/с |
| α_warning | 15° |
| α_crit | 20° |
| α_stall | 27° (sigmoid) |

## Сценарии

Каждый сценарий — анимированный демонстратор (траектория + временные ряды).
Запуск без аргументов открывает интерактивное окно, с аргументом — сохраняет GIF.

### С1 — Установившийся полёт
```bash
python scenarios/s1_steady_flight.py
```
Балансировочный режим с фиксированными trim-управлениями. Проверяет корректность физической модели и интегратора: параметры состояния постоянны, дрейф энергии < 0.01% за 30 с.

### С2 — Кабрирование
```bash
python scenarios/s2_pitch_up.py [results/s2.gif]
```
Трим → θ_ref = +5° → возврат на трим. Каскадный ПИД отрабатывает ступеньку за ~2.4 с. Виден рост высоты и медленная фугоидная осцилляция.

### С3 — Пикирование
```bash
python scenarios/s3_pitch_down.py [results/s3.gif]
```
Зеркально С2: θ_ref = −5°, h₀ = 500 м. ЛА снижается, Va растёт, УА уменьшается.

### С4 — Управляемый срыв + индикатор УА
```bash
python scenarios/s4_stall.py [results/s4.gif]
```
Трим → θ_ref = 20° / газ = 0 → срыв → вывод θ_ref = −5°.

Ключевой элемент — **индикатор УА** (сигнал зонда):

| Уровень | Порог | Цвет |
|---|---|---|
| 0 — НОРМ | α < 15° | зелёный |
| 1 — ПРЕД | α ≥ 15° | жёлтый |
| 2 — КРИТ | α ≥ 20° | оранжевый |
| 3 — СРЫВ | α ≥ 27° | красный |

Отдельный субплот со ступенчатой функцией + фон info-box меняется в реальном времени.

### С5 — Контроль высоты
```bash
python scenarios/s5_altitude_control.py [results/s5.gif]
```
Трим → набор +100 м → возврат. Внешний P-контур (ошибка высоты → θ_ref) поверх каскадного ПИД тангажа. Газ фиксирован = trim (Va не контролируется).

### С6 — Контроль высоты + удержание воздушной скорости
```bash
python scenarios/s6_speed_control.py [results/s6.gif]
```
Идентичен С5 по сценарию, но добавлен независимый **ПИД контур скорости**: `Va_ref = 30 м/с → SpeedController → throttle`. Газ теперь регулируется, Va удерживается в пределах ±0.6 м/с (против ±3.8 м/с в С5).

### С7 — Сравнение оценок угла атаки
```bash
python scenarios/s7_alpha_estimation.py [results/s7.gif]
```
Управление как С6, добавлен попутный ветер 5 м/с. Сравниваются три значения УА:
- **Истинный** — из симулятора (эталон)
- **Зонд** — `measure_angle_of_attack()`, шум σ = 0.57°, нет систематической ошибки
- **ИНС+GPS** — `estimate_alpha_indirect()`, смещение до ±1.3° при манёврах (из-за ветра)

Ключевой вывод: косвенная оценка корректна в штиль, но вносит ветрозависимое смещение при наборе/снижении — именно то, что устраняет зонд.

## Быстрая проверка

```bash
python check.py
```

Проверяет все модули: конфиг, вектор состояния, аэродинамику, ветер, динамику, интеграторы. Выводит `ALL CHECKS PASSED` при успехе.
