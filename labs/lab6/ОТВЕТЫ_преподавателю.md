# Лабораторная 6 — эталонные результаты (для преподавателя)

Моделирование, не эксперимент. FPV-самолёт (m = 2 кг), Va = 16 м/с, h = 200 м, штиль,
датчики — истина (`--sensors truth`), приводы рулей включены. Продольный внешний контур штатной
САУ — TECS (газ), уставки и импульсы — как кнопки редактора. Числа пересчитывает
`python labs/lab6/make_lab6.py`; при `--sensors real` (по умолчанию) отличаются на
шум и запаздывание датчиков. σ — перерегулирование, t_уст — время установления (трубка 5 %).

## Задание 1. Тангаж: от П-регулятора к каскаду

Ступенька θ_ref +5° (кнопка «θ_ref +5°», режим «тангаж»).

**А. П-регулятор по θ:** δe = −Kp·(θ_ref − θ) + δe_бал.

| Kp, °/° | σ, % | t_уст, с |
|---|---|---|
| 0.3 | 0 | 0.94 |
| 0.6 | 0 | 0.31 |
| 1.5 | 32 | 0.61 |
| 3.0 | 67 | 2.1 |
| 3.5 | 75 | 4.7 |
| 4.0 | расходится | — |

Граница устойчивости Kp_гр ≈ 3.5…4. Причина: обратная связь только по углу повышает
собственную частоту короткопериодического движения, а демпфирование не добавляет; фазовое
запаздывание привода (τ) и звена «δe → q → θ» доводит систему до колебательной границы.

**Б. Каскад, Kθ·Kq = 3 (тот же коэффициент «θ → δe», что у Kp = 3):**

| Kq, с | Kθ, 1/с | σ, % | t_уст, с |
|---|---|---|---|
| 0.020 | 150 | 53 | 0.99 |
| 0.0381 | 78.7 | 42 | 0.69 |
| 0.080 | 37.5 | 22 | 0.32 |
| 0.150 | 20.0 | 0 | 0.25 |

Вывод: при одном и том же «статическом» коэффициенте качество определяет демпфирующая
составляющая −Kq·q внутреннего контура.

**В. Kq = 0.15 с, рост Kθ (правило последовательного замыкания контуров):**

| Kθ, 1/с | 10 | 16.2 | 30 | 45 | 60 |
|---|---|---|---|---|---|
| σ, % | 0 | 0 | 15 | 54 | расходится |
| t_уст, с | 0.47 | 0.28 | 0.26 | 0.59 | — |

Штатная настройка (Kθ = 16.2 1/с, Kq = 0.0381 с): σ = 0 %, t_уст = 0.62 с.
Внешний контур можно ускорять, пока его полоса заметно ниже полосы внутреннего (B&M: в 5–10 раз);
дальше аппроксимация «замкнутый внутренний контур ≈ 1» перестаёт работать.

## Задание 2. Высота через тангаж: «накопившийся интеграл»

Схема с внесённой ошибкой `schemes/lab6_2_vysota_oshibka.json` — шаблон «Штатная САУ: высота + тангаж»,
у ПИ высоты обнулены `y_max` и `I_max` (насыщение ±15° осталось после ПИ, отдельным блоком).

| Вариант ПИ высоты | Δh = +10 м: σ / h_max / t_уст | Δh = +50 м: σ / h_max / t_уст |
|---|---|---|
| исходная: без ограничений | 21 % / 212.1 м / 13.2 с | 53 % / 276.7 м / 39.7 с |
| только I_max = 15° | 21 % / 212.1 м / 13.2 с | 4.5 % / 252.2 м / 13.0 с |
| y_max = 15° (условное интегрирование, штатно) | 1.1 % / 210.1 м / 2.8 с | 0.3 % / 250.1 м / 13.0 с |
| без И (Ki = 0) | 0 % / 210.0 м / 2.9 с | 0 % / 250.0 м / 13.0 с |

Ответы на вопросы:
- Ошибка — в ПИ-регуляторе: выход ПИ на ступеньке 50 м доходит до ≈ 370°, а θ_ref ограничен
  ±15° блоком насыщения после регулятора; интеграл копится, пока ЛА набирает высоту на упоре.
- I_max ограничивает накопленное, но не мешает накопить до предела: на 10 м интеграл
  15° не достигает — I_max не помогает; условное интегрирование (интеграл стоит, пока выход
  в упоре) — помогает в обоих случаях.
- Зачем И, если Ki = 0 даёт σ = 0: статическая ошибка появляется, когда балансировочный УА
  отличается от α_бал на входе схемы. Va_ref 16 → 12 м/с (4 нажатия «Va_ref −1»):
  без И h − h_ref = −0.54 м, со штатным ПИ = 0.00 м.

## Задание 3. Курс через крен: функция нормализации угла

Схема с внесённой ошибкой `schemes/lab6_3_kurs_oshibka.json` — «Штатная САУ: курс + крен + скольжение»,
блок «Разность углов» заменён сумматором «+−».

- Проявление ошибки: при χ_ref 0° → … → 180° развороты выполняются правильно; седьмое воздействие (χ_ref = 210° = −150°) —
  ЛА разворачивается на 330° влево вместо 30° вправо (рис. 3). Ошибка
  e = −150° − 180° = −330° вместо +30°. Исправление — «Разность углов» (wrap, слайд 28).

Ступенька χ_ref +90° (три нажатия «χ_ref +30°»):

| Kχ, 1/с | φ_max = 30°: σ / t_уст / \|φ\|max / потеря h | φ_max = 80°: σ / t_уст / \|φ\|max / потеря h |
|---|---|---|
| 0.3 | 0 % / 9.8 с / 30° / 0.3 м | 0 % / 9.6 с / 35° / 0.5 м |
| 1.0 (штатно) | 0 % / 4.9 с / 30° / 0.3 м | 0.5 % / 2.2 с / 63° / 1.9 м |
| 3.0 | 2.6 % / 4.7 с / 30° / 0.3 м | 42 % / 9.2 с / 75° / 3.7 м |
| 10 | 7.2 % / не уст. / 30° / 0.3 м | 72 % / не уст. / 78° / 5.0 м |

Вывод: при Kχ ≥ 3 1/с полоса контура курса подходит к полосе контура крена
(1/τ_φ = 4 рад/с) — колебания курса; ограничение крена превращает их в автоколебания
малой амплитуды, но и без него велики крен и потеря высоты (вертикальная составляющая
подъёмной силы ∝ cos φ).
