## Известные дефекты и долги

- `compute_trim` — линейный по CL/Cm (без sigmoid), только горизонтальный полёт;
  боковой трим (δa против момента винта) не считает.
- Срыв в Cm и боковые производные после срыва не моделируются (нет данных).
- `Log.E_kin` считается по скорости без ветра: при ветре это энергия по земной скорости.
- `control/lqr.py` использует scipy (DARE) — исключение из правила «только numpy».
- Мощность в логах — полезная мощность винта T·Va; электрическая потребует, чтобы
  `propeller()` возвращал обороты.
- Числа в docs/scenarios_report.md сняты на прежнем ЛА.
