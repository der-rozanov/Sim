## Структура репозитория

```
sim/         физика 6DOF: параметры, состояние, динамика, аэродинамика, ветер, земля,
             приводы, интеграторы
control/     САУ: регуляторы, датчики, TECS, защита по α, навигация, LQR, расчёт
             коэффициентов, SAU одним классом, схемы из блоков
runner.py    главный цикл run() → Log, балансировка
flight_logger.py  запись и чтение .flightlog
viz/         viewer.py (2D-графики логов), viewer3d.py (3D), миры и карты, окна
             стенда, карты и редактора схем
scenarios/   s1–s10, GameScenario3D (тренажёр), Bench3D (стенд), BlockLab3D (конструктор)
checks/      проверки здравого смысла и сверка с линейной теорией
archive/     код вне основной линии
results/     .flightlog (генерируются, не в git)
```
