# Лабораторная по Лекции 6: продольный автопилот

Три задания по слайдам 17–24 и 31 лекции (Beard & McLain, гл. 6). Каждое задание — один
сценарий: заполняете функции с пометкой `TODO`, запускаете, смотрите графики и
отвечаете на исследовательские вопросы.

| Задание | Файл | Слайды | Что строите |
|---|---|---|---|
| L1 | `L1_pitch_hold.py` | 18–20, 9 | Контур тангажа: δe = δe* + k_pθ(θᶜ − θ) − k_dθ·q |
| L2 | `L2_altitude_hold.py` | 17, 20–22, 31 | ПИ-контур высоты θᶜ(h) с зоной удержания и анти-виндапом |
| L3 | `L3_airspeed_hold.py` | 23–24 | ПИ-контур скорости δt(Va) |

Подробный разбор (теория, метод решения, ожидаемые результаты, требования к отчёту) —
в [Методичка.md](Методичка.md).

Задания независимы: в L2 и L3 предыдущие контуры уже готовы. Но делать их лучше по порядку.

## Установка и запуск

Нужны Python 3.10+, `numpy`, `matplotlib`:

```
pip install numpy matplotlib
python scenarios/lab6/L1_pitch_hold.py
```

Запускать из корня проекта. Сценарий работает и до выполнения TODO: тогда регулятор
выключен и ЛА летит с балансировочным рулём или газом. Так можно проверить, что всё
установлено.

## Порядок работы

1. В начале файла поставьте свой `VARIANT` (номер выдаёт преподаватель).
2. Прочитайте докстринг: там формулы, подсказки и вопросы.
3. Заполните `TODO`, запустите. Внизу печатается **самопроверка** `[✓]/[✗]`.
   Она сравнивает ваши коэффициенты с численной линеаризацией модели ЛА и проверяет
   переходный процесс.
4. Когда всё `[✓]`, переключайте `EXPERIMENT` и отвечайте на вопросы.
5. Рисунки сохраняются в `results/lab6/` — берите их в отчёт.

Файл `lab6_common.py` править не нужно: в нём балансировка, датчики, метрики и
готовые контуры.

## Отчёт

По каждому заданию:
- ваши коэффициенты (a_θ, k_pθ, k_dθ / k_ph, k_ih / a_V, k_pV, k_iV) и вывод формул;
- вывод самопроверки;
- рисунки экспериментов и таблицы, которые печатает сценарий;
- ответы на вопросы из докстринга, со ссылкой на графики.

## Частые ловушки

- Все углы в коде в **радианах**.
- В модели δe > 0 опускает нос (Cmde < 0), поэтому a_θ3 < 0 и коэффициенты
  k_pθ, k_dθ **отрицательные**. Это правильно.
- Регуляторы работают с полными значениями (θ, h, Va, δt), а не с отклонениями. Поэтому
  в законах управления есть балансировочные δe*, θ*, δt*.
