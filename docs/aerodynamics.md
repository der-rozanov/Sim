## 1. Три коэффициента продольного канала (на примере Aerosonde — пресет `aerosonde_params()`)

### 1.1 Коэффициент подъёмной силы CL

**Нелинейная модель** (sigmoid-смешение линейного CL и CL плоской пластины):

```
σ(α) = (1 + exp(−M·(α − α₀)) + exp(M·(α + α₀)))
       / ((1 + exp(−M·(α − α₀)))·(1 + exp(M·(α + α₀))))

CL_linear     = CL0 + CLa·α
CL_flat_plate = 2·sign(α)·sin²(α)·cos(α)

CL_base = (1 − σ)·CL_linear + σ·CL_flat_plate
```

Добавки от угловой скорости и руля высоты (квазистационарное приближение):

```
ĉ_q = c·q / (2·Va)   (безразмерная угловая скорость)

CL = CL_base + CLq·ĉ_q + CLde·δe
```

**Зачем sigmoid?**  
При малом α (≲10°) поток ламинарен, CL линейно растёт — используем `CL_linear`.  
После срыва (α > α₀) крыло работает как плоская пластина — переходим к `CL_flat_plate`.  
Параметр M=50 задаёт крутизну перехода: при M→∞ это ступенька.

**Параметры (Aerosonde, B&M 2-е изд.):**

| Параметр | Значение | Описание |
|----------|----------|----------|
| CL0 | 0.23 | CL при α=0, δe=0, q=0 |
| CLa | 5.61 рад⁻¹ | Производная по α (≈ πAR/(1+√(1+(AR/2)²)) при AR = 15.2) |
| CLq | 7.95 | Производная по q̂ |
| CLde | 0.13 рад⁻¹ | Производная по рулю высоты |
| M_sigmoid | 50 | Крутизна перехода к срыву |
| alpha_stall | 0.2793 рад ≈ 16° | Центр σ-перехода — **ПОПРАВКА** (в каноне 0.47 рад ≈ 27°) |

**ПОПРАВКА α₀.** С каноническим α₀ = 27° максимум CL = 2.42 при α ≈ 24° — нереально
для крыла малого БПЛА (типично CL_max = 1.2–1.5) и даёт сваливание при 11 м/с.
При α₀ = 16° максимум CL = 1.41 при α ≈ 13° (σ начинает снижать CL за ~3° до α₀),
Va_stall ≈ 14.8 м/с. Пороги индикации привязаны к модели: `alpha_crit` = 13°
(максимум CL), `alpha_warning` = 10°. Значение — оценка, заменяется продувкой/
лётными данными.

**Знак CLde.** `δe > 0` — задняя кромка руля **вниз**: подъёмная сила стабилизатора
растёт (CLde > 0), а момент — пикирующий, т.к. стабилизатор позади ЦТ (Cmde < 0).
Команда «нос вверх» — `δe < 0`.

### 1.2 Коэффициент сопротивления CD

**Докритическая поляра** (вредное + индуктивное), B&M слайд 20:

```
AR = b² / S         (удлинение крыла)

CD_polar = CDp + CL_linear² / (π·e·AR)
```

**После срыва — плоская пластина (ПОПРАВКА):** та же ньютоновская модель, что и
`CL_flat = 2·sin²α·cos α` (нормальная сила `2·sin²α`), её проекция на поток:

```
CD_flat = CDp + 2·|sin α|³

CD = (1 − σ)·CD_polar + σ·CD_flat + CDq·ĉ_q + CDde·|δe|
```

- `CDp` = 0.043 — вредное сопротивление; `e` = 0.9 — коэффициент Освальда.
- В каноне поляра не знает о срыве; смешение по тому же σ(α) согласует CD с CL.
  На 90° CD = 2.04 (плоская пластина бесконечного удлинения — 2.0).
- `CDde` = 0.0135. В каноне член `CDde·δe` со знаком — отрицательный δe уменьшал бы
  сопротивление; **ПОПРАВКА:** `|δe|`. `CDq` = 0.

### 1.3 Коэффициент момента тангажа Cm

**Линейная модель** (точна при малых углах атаки):

```
Cm = Cm0 + Cma·α + Cmq·ĉ_q + Cmde·δe
```

| Параметр | Значение | Физический смысл |
|----------|----------|------------------|
| Cm0 | 0.0135 | Момент при нулевых углах |
| Cma | −2.74 рад⁻¹ | **Устойчивость по тангажу**: Cma < 0 — при росте α ЛА сам стремится уменьшить α |
| Cmq | −38.21 | **Демпфирование тангажа**: гасит колебания по тангажу |
| Cmde | −0.99 рад⁻¹ | Эффективность руля высоты (δe > 0 — нос вниз) |

Срыв в Cm не моделируется (как и в каноне): на закритических α линейный Cm
завышает пикирующий момент. Надёжных данных для поправки нет — открытый вопрос.

## 2. Перевод сил в связанную СК

Подъёмная сила и сопротивление определены в **скоростной (поточной) СК** (x_s ∥ Va).  
Поворот в связанную СК (вращение на угол α вокруг y):

```
fx_aero = −D·cos(α) + L·sin(α)
fz_aero = −D·sin(α) − L·cos(α)
```

Матрица поворота (2D):
```
[fx_aero]   [cos(α)   sin(α)] [−D]
[fz_aero] = [−sin(α)  cos(α)] [−L]
```

При нормальном полёте (малый α):
- `fz_aero ≈ −L < 0` — тянет против z_b (вверх), удерживает ЛА ✓
- `fx_aero ≈ −D < 0` — тянет против x_b (назад), тормозит ✓

## 5. Боковой канал

Линейная модель по B&M (ур. 4.14–4.15), безразмерные угловые скорости
`p̂ = b·p/(2Va)`, `r̂ = b·r/(2Va)`:

```
CY    = CY0    + CY_beta·β    + CY_p·p̂    + CY_r·r̂    + CY_da·δa    + CY_dr·δr
Croll = Croll0 + Croll_beta·β + Croll_p·p̂ + Croll_r·r̂ + Croll_da·δa + Croll_dr·δr
Cn    = Cn0    + Cn_beta·β    + Cn_p·p̂    + Cn_r·r̂    + Cn_da·δa    + Cn_dr·δr

fy = q_dyn·S·CY,   L_roll = q_dyn·S·b·Croll,   N_yaw = q_dyn·S·b·Cn
```

`Croll` — коэффициент момента крена (в B&M `C_l`); переименован, чтобы не путать
с Cl подъёмной силы (глоссарий проекта). Реализация — `aero.aero_lateral()`.

Значения — Aerosonde, B&M 2-е изд. (РЕШ-18), подлежат замене:

| | β | p̂ | r̂ | δa | δr |
|---|---|---|---|---|---|
| CY    | −0.98 | 0 | 0 | 0.075 | +0.19 |
| Croll | −0.13 | −0.51 | 0.25 | 0.17 | 0.0024 |
| Cn    | 0.073 | 0.069 | −0.095 | −0.011 | −0.069 |

Свободные члены CY0 = Croll0 = Cn0 = 0 (симметричный ЛА).

**Знак CY_dr.** В табл. E.2 1-го издания CY_dr = −0.17. При принятом знаке δr
(задняя кромка влево) сила на киле направлена вправо (+y), т.е. по физике
CY_dr > 0 (РЕШ-15). Во 2-м издании авторы исправили сами: CY_dr = +0.19.

**Реактивный момент винта** (РЕШ-19) добавляется к моменту крена: `L_roll −= Q_prop`
(B&M слайд 37). На балансировке Q ≈ 0.4–0.9 Н·м кренит ЛА влево; парируется
δa ≈ 0.3–0.5° — в продольных сценариях это делает САУ по крену (`RollHold`).
