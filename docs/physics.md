# Физическая модель симулятора

Источник: Beard & McLain «Small Unmanned Aircraft», гл. 3–4.  
Модель: полная нелинейная 6DOF (продольный + боковой каналы).  
Реализация: `state.py`, `dynamics.py`, `aero.py`, `wind.py`.

---

## 1. Системы координат

### 1.1 Земная (нормальная) СК

Правая СК «север–восток–вниз» (NED), хранится в виде:
**x** — на север (при ψ=0 — вперёд по полёту), **y** — на восток (при ψ=0 — вправо),
**h** — высота, вверх (h = −z_NED).

Ветер задаётся в этой же СК тройкой `(Vwx, Vwh, Vwy)` — скорость движения
воздушной массы:
- `Vwx` — на север (при ψ=0 — попутный ветер);
- `Vwh` — вверх (восходящий поток);
- `Vwy` — на восток (при ψ=0 — боковой ветер, дующий слева направо по полёту).

Порядок `(x, h, y)` выбран намеренно: боковая составляющая дописана в конец,
поэтому весь продольный код, работающий с парой `(Vwx, Vwh)`, не изменился.

### 1.2 Связанная СК (`body frame`)

**x_b** — к носу, **y_b** — на правое крыло, **z_b** — вниз (правая СК).
В ней хранятся скорости `(u, v, w)` и угловые скорости `(p, q, r)`,
записываются уравнения Ньютона и Эйлера.

### 1.3 Углы Эйлера (последовательность ψ → θ → φ)

- ψ — угол рыскания (курс продольной оси), поворот вокруг вертикали, > 0 — вправо;
- θ — угол тангажа, **θ > 0** — нос выше горизонта;
- φ — угол крена, **φ > 0** — правое крыло вниз.

Матрица перехода из связанной СК в земную NED (`sX = sin X`, `cX = cos X`):

```
        | cθcψ   sφsθcψ − cφsψ   cφsθcψ + sφsψ |
R_b→e = | cθsψ   sφsθsψ + cφcψ   cφsθsψ − sφcψ |
        | −sθ    sφcθ            cφcθ          |
```

Обратный переход (земная → связанная) — транспонированная матрица `Rᵀ`.

### 1.4 Аэродинамические углы: УА α, УС β и воздушная скорость Va

Ветер переводится в связанную СК: `(u_w, v_w, w_w) = Rᵀ · (Vwx, Vwy, −Vwh)`.
Скорость относительно воздуха:

```
ur = u − u_w,   vr = v − v_w,   wr = w − w_w

Va    = √(ur² + vr² + wr²)
alpha = arctan2(wr, ur)          (УА)
beta  = arcsin(vr / Va)          (УС, > 0 — набегающий поток справа)
```

При φ = ψ = 0, v = 0, Vwy = 0 эти формулы совпадают с прежними продольными:
`u_w = Vwx·cosθ + Vwh·sinθ`, `w_w = Vwx·sinθ − Vwh·cosθ`, `β = 0`.

**Принципиально**: АУ считаются по воздушной скорости, не по земной.
Именно поэтому при ветре косвенная оценка `α ≈ θ − γ_GPS` даёт ошибку.

## 2. Вектор состояния

```
state = [u, w, q, θ, x, h,  v, p, r, φ, ψ, y]   (numpy array, 12 элементов)
         └── продольный ──┘  └──── боковой ───┘
```

| Индекс | Имя | Описание | Ед. |
|--------|-----|----------|-----|
| 0 | `U` | Скорость вдоль x_b (вперёд) | м/с |
| 1 | `W` | Скорость вдоль z_b (вниз) | м/с |
| 2 | `Q` | Угловая скорость тангажа | рад/с |
| 3 | `THETA` | Угол тангажа | рад |
| 4 | `X` | Координата на север | м |
| 5 | `H` | Высота (вверх положительно) | м |
| 6 | `V` | Скорость вдоль y_b (вправо) | м/с |
| 7 | `P` | Угловая скорость крена | рад/с |
| 8 | `R` | Угловая скорость рыскания | рад/с |
| 9 | `PHI` | Угол крена | рад |
| 10 | `PSI` | Угол рыскания | рад |
| 11 | `Y` | Координата на восток | м |

Индексы 0..5 совпадают с прежним продольным вектором — боковой канал добавлен
расширением, не переписыванием. Доступ только по имени:
```python
from sim.state import U, W, Q, THETA, X, H, V, P, R, PHI, PSI, Y
```

Вектор управления: `controls = [δe, δt, δa, δr]` (индексы `DE, DT, DA, DR`).
Если сценарий отдаёт только `[δe, δt]`, недостающие δa = δr = 0.

Знаки рулей (B&M, правило правой руки):
- δe > 0 — задняя кромка руля высоты вниз (нос вниз);
- δa > 0 — у левого элерона задняя кромка вниз, у правого вверх (крен вправо);
- δr > 0 — задняя кромка руля направления влево (нос влево).

## 3. Уравнения движения (полная нелинейная модель 6DOF)

Реализованы в `dynamics.derivatives()`. Это дословная запись для приложения Б
(Beard & McLain, ур. 3.14–3.17).

### 3.1 Поступательное движение (2-й закон Ньютона в связанной СК)

```
du/dt = r·v − q·w + fx / m
dv/dt = p·w − r·u + fy / m
dw/dt = q·u − p·v + fz / m
```

`(fx, fy, fz)` — сумма аэродинамических сил, тяги и веса в связанной СК.
Перекрёстные члены — следствие того, что скорости заданы во вращающейся СК.

### 3.2 Вращательное движение (уравнения Эйлера с центробежным моментом Jxz)

ЛА симметричен относительно плоскости x_b z_b, поэтому Jxy = Jyz = 0.

```
Γ  = Jx·Jz − Jxz²
Γ1 = Jxz·(Jx − Jy + Jz) / Γ          Γ5 = (Jz − Jx) / Jy
Γ2 = (Jz·(Jz − Jy) + Jxz²) / Γ       Γ6 = Jxz / Jy
Γ3 = Jz / Γ                          Γ7 = ((Jx − Jy)·Jx + Jxz²) / Γ
Γ4 = Jxz / Γ                         Γ8 = Jx / Γ

dp/dt = Γ1·p·q − Γ2·q·r + Γ3·L_roll + Γ4·N_yaw
dq/dt = Γ5·p·r − Γ6·(p² − r²) + M_pitch / Jy
dr/dt = Γ7·p·q − Γ1·q·r + Γ4·L_roll + Γ8·N_yaw
```

`L_roll, M_pitch, N_yaw` — моменты крена, тангажа, рыскания вокруг x_b, y_b, z_b.
При Jxz = 0 крен и рыскание связаны только через аэродинамику.

### 3.3 Кинематика углов Эйлера

```
dφ/dt = p + (q·sinφ + r·cosφ)·tanθ
dθ/dt = q·cosφ − r·sinφ
dψ/dt = (q·sinφ + r·cosφ) / cosθ
```

Особенность при θ = ±90° — для самолётного ЛА вне рабочей области.

### 3.4 Кинематика положения

Земная скорость = `R_b→e · (u, v, w)`:

```
dx/dt =  cθcψ·u + (sφsθcψ − cφsψ)·v + (cφsθcψ + sφsψ)·w
dy/dt =  cθsψ·u + (sφsθsψ + cφcψ)·v + (cφsθsψ − sφcψ)·w
dh/dt =  sθ·u   − sφcθ·v            − cφcθ·w
```

### 3.5 Вырождение в продольный канал

При `v = p = r = φ = ψ = 0` и `δa = δr = 0` (симметричная аэродинамика):

```
du/dt = −q·w + fx/m        dθ/dt = q
dw/dt =  q·u + fz/m        dx/dt = u·cosθ + w·sinθ
dq/dt = M_pitch / Jy       dh/dt = u·sinθ − w·cosθ
```

— это в точности прежние продольные уравнения. Проверяется в `checks/check.py`
(регрессия продольного канала).

> **Исправление (2026-10-06).** В продольной версии было `dx/dt = u·cosθ − w·sinθ`
> (ошибка знака, на динамику не влияла). Исправлено одновременно в трёх местах:
> `dynamics` (через матрицу R), `state.kinematic_gamma`, `sensors.measure_gps_velocity_earth`.
> Следствие: немного меняются x(t) и γ_GPS, результаты s7–s9 нужно перезапустить.

## 4. Силы и моменты

### 4.1 Гравитация в связанной СК

```
fx_grav = −m·g·sinθ
fy_grav = +m·g·cosθ·sinφ
fz_grav = +m·g·cosθ·cosφ
```

### 4.2 Тяга и момент винта (электромотор + винт)

Тянущий винт, ось — вдоль x_b. Модель B&M 2-е изд., разд. 4.3 (слайды 36–37):

```
V_in = V_max·δt                              — напряжение на моторе
K_V = K_Q = 60 / (2π·KV_rpm)                 — постоянные мотора, В·с/рад = Н·м/А

Обороты Ω — положительный корень баланса моментов мотора и винта:
  (ρD⁵/(2π)²·C_Q0)·Ω² + (ρD⁴/(2π)·C_Q1·Va + K_Q·K_V/R)·Ω
    + (ρD³·C_Q2·Va² − K_Q·V_in/R + K_Q·i0) = 0

J  = 2π·Va / (Ω·D)                           — относительная поступь
CT = C_T2·J² + C_T1·J + C_T0,  CQ = C_Q2·J² + C_Q1·J + C_Q0
T  = ρ·(Ω/2π)²·D⁴·CT,          Q_prop = ρ·(Ω/2π)²·D⁵·CQ
```

**ПОПРАВКА — свободное вращение (РЕШ-19).** Регулятор оборотов не рекуперирует:
ток мотора `i = (V_in − K_V·Ω)/R ≥ 0`. Если по уравнению выше i < 0 (малый газ на
скорости), мотор отключён, на валу только трение `K_Q·i0`, винт авторотирует:

```
(ρD⁵/(2π)²·C_Q0)·Ω² + (ρD⁴/(2π)·C_Q1·Va)·Ω + (ρD³·C_Q2·Va² + K_Q·i0) = 0
```

Без поправки V_in = 0 — это короткозамкнутая обмотка (винт заторможен) и
сопротивление −33 Н при 30 м/с; с поправкой −6.4 Н (J ≈ 0.73, в пределах продувки).

Реактивный момент `−Q_prop` добавляется к моменту крена (B&M слайд 37: `Mx −= Q`).

Параметры FPV-самолёта (РЕШ-20): винт APC 11×7E (D = 0.279 м, CT/CQ — продувка
UIUC), мотор AT2814 900KV (R = 0.082 Ом, i0 = 1.2 А), АКБ 4S (V_max = 14.8 В).
Статическая тяга 24.6 Н (T/W = 1.25); Va_max горизонта ≈ 31.5 м/с.
Aerosonde (`aerosonde_params()`): винт 20″, KV 145, 12S, статическая тяга 84.6 Н.

### 4.3 Продольные аэродинамические силы и момент тангажа

Подъёмная `L` и сопротивление `D` — в поточной СК, затем поворот на α:

```
fx_aero = −D·cos(α) + L·sin(α)
fz_aero = −D·sin(α) − L·cos(α)
M_pitch = q_dyn·S·c·Cm(α, q̂, δe)
```

Влияние β на продольные силы не учитывается (стандартное приближение B&M).
Подробно коэффициенты CL, CD, Cm — в `aerodynamics.md`.

### 4.4 Боковые аэродинамические сила и моменты

Безразмерные угловые скорости: `p̂ = b·p/(2Va)`, `r̂ = b·r/(2Va)`, `q_dyn = ½ρVa²`.

```
fy     = q_dyn·S   · (CY0    + CY_beta·β    + CY_p·p̂    + CY_r·r̂    + CY_da·δa    + CY_dr·δr)
L_roll = q_dyn·S·b · (Croll0 + Croll_beta·β + Croll_p·p̂ + Croll_r·r̂ + Croll_da·δa + Croll_dr·δr)
N_yaw  = q_dyn·S·b · (Cn0    + Cn_beta·β    + Cn_p·p̂    + Cn_r·r̂    + Cn_da·δa    + Cn_dr·δr)
```

Обозначение момента крена — `Croll` (в B&M — `C_l`), чтобы не путать с Cl
подъёмной силы из глоссария проекта.

Смысл ключевых производных (знаки — для устойчивого ЛА):

| Производная | Знак | Смысл |
|---|---|---|
| `Croll_beta` | < 0 | поперечная устойчивость («эффект V крыла») |
| `Croll_p` | < 0 | демпфирование крена |
| `Cn_beta` | > 0 | путевая (флюгерная) устойчивость |
| `Cn_r` | < 0 | демпфирование рыскания |
| `Croll_da` | > 0 | эффективность элеронов (δa > 0 → крен вправо) |
| `Cn_dr` | < 0 | эффективность руля направления (δr > 0 → нос влево) |

### 4.5 Суммарные силы

```
fx = fx_aero + T + fx_grav
fy = fy_aero     + fy_grav
fz = fz_aero     + fz_grav
```

## 5. Балансировочные условия (трим)

Прямолинейный горизонтальный полёт без крена (φ = β = 0). Боковой канал
тримируется малыми δa ≈ 0.3–0.5°, δr ≈ −0.05° против реактивного момента винта —
`compute_trim()` их не считает, в сценариях крен держит `RollHold` (РЕШ-19),
в `checks/check_lateral.py` — боковой трим решением 2×2 по ṗ = ṙ = 0. Продольный канал: `du/dt = dw/dt = dq/dt = dθ/dt = 0`, `γ = 0`.

Из условия `L = mg`:

```
CL_req = 2·m·g / (ρ·Va²·S)
```

Из `CL = 0` и `Cm = 0` — линейная система 2×2 для `(α_trim, δe_trim)`:

```
[CLa   CLde] [α   ]   [CL_req − CL0]
[Cma   Cmde] [δe  ] = [−Cm0        ]
```

Из `T(δt, Va) = D` — газ `δt_trim` (бисекцией: модель винта не обращается
аналитически; в D входит `CDde·|δe|`). Реализовано в `runner.compute_trim()`.

## 6. Механическая энергия

```
E_kin   = 0.5 · m · Va²
E_pot   = m · g · h
E_total = E_kin + E_pot
```

**Va** здесь — воздушная скорость (учитывает ветер).  
В тримовом полёте `dE_total/dt ≈ 0` (тяга = сопротивлению).  
Отклонение от этого значения — числовой дрейф интегратора  
(используется в `plot_integrator_check`).

## 7. Ключевые упрощения модели

| Упрощение | Последствие |
|-----------|-------------|
| Боковая аэродинамика линейна по β, p̂, r̂, δa, δr | Корректна при малых β (до ~10–15°) |
| Влияние β на CL, CD, Cm не учитывается | Погрешность продольных сил при больших скольжениях |
| Сжимаемость воздуха не учтена | Корректно до ~150 м/с (число Маха < 0.45) |
| Постоянная плотность воздуха ρ | ≈ 5% на 500 м над уровнем ρ |
| Линейная модель Cm по α | Точна до срыва (~13°); после срыва завышает пикирующий момент |
| Масса постоянная | Расход топлива не учитывается |
| Тяга вдоль x_b, винт без гироскопического момента и обдува оперения | Учтён только реактивный момент Q_prop по крену |
| CT(J), CQ(J) — квадратичные аппроксимации продувки (J ≤ ~0.7) | За пределами — экстраполяция; свободное вращение держит J ≈ 0.73 |
