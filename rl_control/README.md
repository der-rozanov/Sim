# RL-контроллер тангажа — статус разработки

Экспериментальный модуль. В диссертацию не входит — материал для слайдов.
Цель: показать что самолёт в принципе можно научить держать тангаж через RL.

---

## Что реализовано

| Файл | Назначение |
|---|---|
| `agent.py` | `QLearningAgent` — Q-таблица, epsilon-greedy, save/load |
| `train.py` | Тренировочный цикл, прогресс-бар, параллельный запуск |
| `visualize.py` | Графики: кривая обучения, траектории эпизодов, тепловая карта Q-таблицы |
| `demo.py` | Демо-прогон 50 с со ступенчатыми уставками, анимация в стиле scenarios/ |
| `q_table.npy` | Обученная Q-таблица (генерируется) |
| `de_trim.npy` | Тримовое положение руля (генерируется, нужно для demo.py) |
| `rewards.npy` | История наград по эпизодам (генерируется) |
| `episode_logs.npz` | Траектории логируемых эпизодов (генерируется, только однопоточный режим) |

## Как запускать

```bash
# Однопоточно — прогресс-бар, после обучения открываются графики
python rl_control/train.py

# Параллельно — N независимых агентов, берётся лучший
python rl_control/train.py --workers 12

# Демо-прогон с анимацией (нужен q_table.npy)
python rl_control/demo.py

# Сохранить демо в GIF
python rl_control/demo.py results/rl_demo.gif

# Только графики обучения из сохранённых файлов
python rl_control/visualize.py
```

## Пространство состояний и действий

**Состояние:** `(theta_err, q)` — ошибка тангажа и угловая скорость

| Переменная | Диапазон | Бинов | Шаг |
|---|---|---|---|
| theta_err | −20° .. +20° | 21 | 2° |
| q | −1.5 .. +1.5 рад/с | 15 | 0.2 рад/с |

**Действия:** 5 дискретных смещений руля высоты относительно `de_trim`:
`[-0.30, -0.15, 0.0, +0.15, +0.30]` рад = `[-17°, -8.6°, 0°, +8.6°, +17°]`

**Размер Q-таблицы:** 21 × 15 × 5 = **1575 ячеек**

## Текущие гиперпараметры

| Параметр | Значение | Комментарий |
|---|---|---|
| alpha (lr) | 0.1 | скорость обучения |
| gamma | 0.95 | дисконт |
| epsilon | 1.0 → 0.05 | линейный спад за 80% эпизодов |
| ep_duration | 10 с | длина эпизода (1000 шагов) |
| n_episodes | 5000 | на воркер |
| ACTION_SMOOTH_K | 3.0 | штраф за изменение руля |
| throttle | de_trim (фиксированный) | тяга не управляется |
| ветер | выключен | обучение без ветра |

**Функция награды:**
```
r = -|theta_err_deg|              # основной сигнал
  - 0.1 * q_deg²                 # штраф за раскачку
  - K * (Δde_deg)² / 1000        # штраф за дёрганье руля
  - 50 * (alpha > alpha_stall)   # штраф за срыв
```

## Известные проблемы

### Reward hacking — дизеринг руля

Агент научился **быстро переключаться между соседними позициями руля** вместо плавного управления. Формально не нарушает штраф — каждый шаг всего 8.6°, платит минимум. Эффект: руль дрожит ±8.6° вокруг одного положения.

Это **dithering** — в теории управления реальная техника, но не то что нужно.

**Корень проблемы:** штраф `k*(Δde)²` платится за каждый шаг независимо. Бесконечное дрожание стоит столько же сколько одно плавное движение.

### Слабое слежение за уставкой

При theta_ref = 8° агент выходит только на ~3°. Причина — аэродинамически устойчивый ЛА (Cma < 0) стремится вернуться к трим-альфа, агент не научился достаточно агрессивно противодействовать этому.

## Следующие шаги (на выбор)

### Фикс дизеринга (по приоритету)

**Вариант А — штраф за реверс (проще всего):**
Добавить отдельный штраф за смену знака изменения руля:
```python
if prev_change * curr_change < 0:
    reward -= REVERSAL_PENALTY   # ~5–10
```

**Вариант Б — штраф за дисперсию последних N действий (элегантно):**
Скользящее окно последних 10 позиций руля — штрафовать `np.std(recent_de)`.
Агент учится держать руль стабильно.

**Вариант В — минимальное время удержания (грубо, быстро):**
Руль можно менять только раз в K=5 шагов. Не RL, но решает проблему мгновенно.

### Улучшение слежения

- Более частые действия или больше дискретных уровней (7–9 вместо 5)
- Увеличить эпизоды до 15–20 с
- Попробовать штраф `-theta_err²` вместо `-|theta_err|` (сильнее штрафует большие ошибки)
