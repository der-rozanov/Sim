# Архив

Код, который больше не входит в основную линию симулятора, но сохранён для
воспроизводимости. В регрессию (`scenarios/s*.py`) не входит.

## probe/ — сравнение «зонд vs косвенная оценка УА» (магистерская работа)

Тематика на паузе с 2026-10-06. Состояние на момент защиты — тег git `diploma`.

В тексте диплома и под тегом `diploma` эти сценарии — С7–С10 (`scenarios/s7…s10`). С 2026-10-13 они переименованы в П7–П10 (`p7…p10`), а номера s7–s10 получили бывшие s11–s14 (LQR, разворот, боковой ветер, полёт по точкам).

| Файл | Содержание |
|---|---|
| `estimators.py` | `estimate_alpha_indirect()` — косвенная оценка УА: θ (ИНС) − γ (GPS) |
| `p7_alpha_estimation.py` | Оценки УА: зонд vs ИНС+GPS при попутном ветре |
| `p8_energy_comparison.py` | То же + накопленная энергия (прокси throttle·Va) |
| `p8_b_motor_work.py` | Работа мотора W = ∫T·Va dt |
| `p9_paired_probe_comparison.py` | Парный прогон «с зондом vs без зонда» |
| `p10_aua_gust_protection.py` | АУА против попутного порыва |

Запуск — из корня репозитория: `python archive/probe/p9_paired_probe_comparison.py`.
Сценарии настроены под прежние параметры ЛА; числа в docs/scenarios_report.md
получены до перехода на FPV (РЕШ-20) — для новых выводов перезапустить.
